# Platon Premarket — конкурсная заявка

## Номинация

AI-агент для облигационного портфеля. Дополнительно проект показывает платформенный потенциал: в одном PWA живут несколько ботов.

## Проблема

Частному инвестору в облигациях нужно одновременно держать в голове:

- состав портфеля и концентрацию;
- доходность и дюрацию;
- купоны, оферты и погашения;
- кредитный риск и ликвидность;
- налоги и альтернативы на рынке.

Брокерские приложения показывают данные, но не отвечают на вопрос «что делать дальше». ChatGPT-обёртки не умеют считать облигационную математику и не имеют доступа к счёту.

## Решение

Bond Copilot — AI-агент, который:

1. Читает портфель через T-Invest MCP.
2. Считает метрики локальным детерминированным ядром.
3. Объясняет риски и возможности обычным языком.
4. Собирает swap-план: что продать и что купить.
5. Показывает эффект: доходность, дюрация, концентрация, свободный кэш.
6. Ждёт подтверждения пользователя.
7. Выполняет сделку в sandbox через MCP и пишет аудит.

Ключевой принцип: LLM объясняет, но не считает числа и не торгует без подтверждения.

## Демо на 3 минуты

1. Открыть установленное PWA на телефоне.
2. Показать портфель 5,77 млн ₽, 6 выпусков, графики аллокации и доходности/дюрации.
3. Спросить: «Где риск?» — агент показывает концентрацию ТГК-14 27% и рейтинг BBB-.
4. Спросить: «Предложи замену» — агент показывает карточку swap: продать 200 шт. ТГК-14, купить 200 шт. МГКЛ 2Р9, эффект +0,1 п.п. доходности и снижение доли.
5. Нажать «Подтвердить в sandbox» — появляется audit ID.
6. Переключиться на Freelance Radar — второй модуль с реальными заказами из SQLite.
7. Показать установку PWA и профиль с состоянием MCP.

## Почему это сильная заявка

- не чат-обёртка, а продукт с собственной облигационной математикой;
- T-Invest MCP используется по назначению: счёт, данные, сделки;
- есть Risk Officer и human-in-the-loop;
- есть второй модуль, который доказывает расширяемость платформы;
- мобильный PWA, а не Streamlit-дашборд;
- read-only токены и sandbox по умолчанию.

## Архитектура

- `apps/web` — Next.js 16, React 19, Tailwind, Recharts, PWA manifest и service worker.
- `services/api` — FastAPI, Pydantic, API gateway, MCP-клиент.
- `modules/bond` — Bond Copilot: портфель, чат, действия.
- `modules/freelance` — read-only лента заказов из SQLite.
- `infra` — Caddy и Docker Compose.
- Домен: https://platoninvest.pro
- API: https://platoninvest.pro/api
- Swagger: https://platoninvest.pro/api/docs

## Что уже работает

- PWA установка и офлайн-shell.
- Мобильный и десктопный интерфейс.
- Портфель, графики, позиции, календарь, кандидаты на замену.
- Чат с детерминированными сценариями.
- Карточка сделки и подтверждение в sandbox (mock).

- Freelance Radar с реальной базой заказов.

## Что осталось до заявки

- Получить T-Invest sandbox token.
- Подключить MCP: `tools/list`, портфель, котировки, sandbox-ордера.
- Заменить mock-подтверждение на реальный MCP order-tool.
- Включить LLM и проверить ответы на демо-сценариях.
- Записать demo-видео.
- Подготовить pitch и ответы на вопросы жюри.

## Риски и ответы

- «LLM может ошибиться» — числа считает код, LLM только объясняет.
- «Данные клиента» — токен только на backend, в демо sandbox, персональные данные не сохраняются.
- «Автоторговля» — по умолчанию read-only, сделка только после подтверждения.
- «Зачем PWA» — мобильный сценарий, установка на экран, пуши, единая платформа для нескольких ботов.
- «Почему не Telegram/VK» — VK-бот остаётся каналом, PWA даёт полноценный продуктовый интерфейс и демо для жюри.
