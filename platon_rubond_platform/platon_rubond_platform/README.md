# Platon-RuBond-bot

Интеллектуальный ИИ-агент рынка облигаций РФ.

Автономный агент на базе LangChain для мониторинга рынка корпоративных и государственных облигаций Московской Биржи, парсинга новостей, семантического анализа, расчёта доходности и автоматических уведомлений.

## Архитектура

Проект следует принципам SOLID, ООП и модульности. Полная структура описана в Техническом задании (PRD).

```
platon_rubond_platform/
├── app.py
├── requirements.txt
├── .env.example
├── README.md
└── src/
    ├── config.py
    ├── data_providers/
    ├── agent/
    ├── memory/
    ├── analytics/
    ├── ui/
    └── utils/
```

## Быстрый старт (каркас)

1. Скопируйте `.env.example` → `.env` и заполните ключи.
2. Установите зависимости: `pip install -r requirements.txt`
3. Запуск UI: `streamlit run app.py`

## Статус

На текущем этапе реализован только каркас проекта (скелет классов и модулей). Бизнес-логика будет добавляться поэтапно.
